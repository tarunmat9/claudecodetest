# Tic-Tac-Toe

A browser-based tic-tac-toe game where you play against the computer.

## How to play

Open `index.html` in any modern browser. You play as **X**, the computer plays as **O**.

## Difficulty levels

- **Easy** — computer picks random moves
- **Medium** — computer wins or blocks when it can, otherwise random
- **Hard** — unbeatable minimax AI
